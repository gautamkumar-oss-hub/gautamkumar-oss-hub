## Selected Projects

### Cloud-Native Telemedicine Consultation Platform
[Repository](https://github.com/gautamkumar-oss-hub/cloud-native-healthcare-platform)

A microservices-based healthcare platform for patient records and appointment scheduling, with AI-powered natural-language search over clinical notes.

- Independent Spring Boot services (patient, appointment, document search) exposing REST and GraphQL APIs, communicating via Apache Kafka; sustained ~150 req/sec in local load testing, validated with JUnit/Mockito
- LangChain-based RAG pipeline over vector embeddings for clinical note retrieval, achieving ~92% retrieval accuracy on a test query set
- Redis caching for high-read lookups, cutting average latency from ~180ms to ~45ms and reducing repeated database load by an estimated 60%
- 5 microservices containerized and deployed to AWS EKS (Docker, ECR), with RDS, S3, and an ALB for routing; Jenkins CI/CD and CloudWatch monitoring cut deployment time from ~20 minutes to under 5

**Concepts:** microservices, event-driven architecture, RAG, caching, container orchestration, CI/CD

### Private Search Engine
[Repository](https://github.com/gautamkumar-oss-hub/Private-Search-Engine)

A privacy-focused web search engine with no user tracking or search-history profiling.
